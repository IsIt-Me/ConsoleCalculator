# ConsoleCalculator
Консольный калькулятор на Qt 6.12 и C++17.

Поддерживаются операции с обычными числами и дробями: сложение, вычитание, умножение и деление. Также доступны сброс, справка и выход. Результаты и операции с дробями записываются в history.txt.

## Сборка

Открыть ConsoleCalculator.pro в Qt Creator, выбрать Qt 6.12 с MSVC и выполнить Build → Build Project.

## Запуск

Запустить программу из Qt Creator или через созданный исполняемый файл.
